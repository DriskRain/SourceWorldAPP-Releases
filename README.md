# 源世界 SourceWorldAPP

这里是「源世界」Android 应用的正式版本发布仓库，仅用于保存发布说明、免责声明和正式安装包，不存放项目源代码。

## 下载与安装

1. 在仓库的 **Releases / 发行版** 页面下载最新的正式 APK。
2. 同时下载对应的 `SHA256SUMS.txt`，核对 APK 的 SHA-256 校验值。
3. 在 Android 系统中允许当前文件管理器或浏览器“安装未知应用”，然后打开 APK 完成安装。
4. 从旧版本升级时，无需卸载应用；但安装包必须使用相同包名、相同正式签名证书，并具有更高的 `versionCode`。

当前正式版本为 `1.0.4`，正式包名为 `com.driskrain.sourceworldapp`。

## 官方发布渠道

- GitHub：本仓库的 Releases 页面
- Gitee：同名发布仓库的发行版页面

两个平台发布的同一版本应使用完全相同的 APK，并公布相同的 SHA-256 校验值。若校验值不同，请停止安装并等待官方说明。

## 使用说明

源世界是本地内容与用户自定义订阅源的阅读、漫画和视频聚合工具。应用本身不内置或运营第三方内容服务；实际可访问内容、稳定性和合法性取决于用户导入的订阅源及其对应网站。

安装或使用前，请先阅读 [免责声明](DISCLAIMER.md) 与 [隐私说明](PRIVACY.md)。应用使用的第三方开源组件及对应许可可在应用内“我的 → 声明 → 开源许可”查看。

## 隐私承诺

源世界不设置账号，不向开发者或自有服务器收集、上传、出售用户的个人信息与使用数据。用户选中的文件、订阅源、收藏、搜索历史及阅读/播放进度只在设备本地处理；用户主动访问第三方订阅源时，对方网站仍会收到完成连接所需的网络信息。完整边界见 [隐私说明](PRIVACY.md)。

最新版本说明见 [`RELEASE_NOTES_v1.0.4.md`](RELEASE_NOTES_v1.0.4.md)，历史说明保留在 [`RELEASE_NOTES_v1.0.3.md`](RELEASE_NOTES_v1.0.3.md)、 [`RELEASE_NOTES_v1.0.2.md`](RELEASE_NOTES_v1.0.2.md)、[`RELEASE_NOTES_v1.0.1.md`](RELEASE_NOTES_v1.0.1.md) 与 [`RELEASE_NOTES_v1.0.0.md`](RELEASE_NOTES_v1.0.0.md)。每个版本的 APK 与 `SHA256SUMS.txt` 均作为 GitHub/Gitee 发行版附件提供，两个平台使用完全相同的文件。

## 联系与反馈

应用自身的功能、隐私或发布问题可通过应用内“我的 → 我们”查看 QQ 群，或通过 [GitHub Issues](https://github.com/DriskRain/SourceWorldAPP-Releases/issues) 联系维护者。第三方内容、订阅源或网站的可用性与数据处理问题，请优先联系对应服务提供方或订阅源维护者。

## 安全提醒

- 只从本仓库或对应的官方 Gitee 发布仓库下载安装包。
- 不要安装来源不明、被重新签名或校验失败的 APK。
- 正式版更新将始终使用同一正式签名证书。
- 本仓库不会上传签名私钥、密码、Token、用户数据或项目源代码。
